sCAN
#####

.. contents::
   :local:
   :depth: 2

This documentation outlines the sCAN Soft Peripheral.
It covers setup, integration, and operational guidelines for using sCAN through the nrfx driver API, alongside detailed descriptions of limitations and performance considerations.

.. note::
   The current version of sCAN is based on CAN Specification 2.0 A/B
